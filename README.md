# PetroHrys.com

Source for [petrohrys.com](https://www.petrohrys.com) — an independent research
and publishing site, its Research Center datasets, and the generators that build
them.

The site ships as raw static files. There is no root `package.json`, no build
server and no dependency install step; see `docs/business-directories-runbook.md`
for how the datasets are validated, built and tested.

## Research Center

| Collection | Data |
|---|---|
| Business Directories | `data/business-directories/` |
| Marketplace & Classified Platforms | `data/marketplaces/` |
| Media / PR / Publishing Platforms | `data/media-pr-publishing/` |
| Distribution Intelligence / Planner | `data/distribution-planner/` |

Scoring methodology: `docs/petrohrys-score-methodology.md`.
